# 施昱廷個人品牌官網

> 用職能治療師的眼睛，看懂生活
> 把復能，帶進每一個家、每一場培訓

職能治療師、高齡友善住宅顧問、培訓講師 — 施昱廷的個人品牌官網。

## 技術

純靜態 HTML / CSS / JS — 無框架、無 build step、開箱即用。

- **字型**：DM Serif Display Italic + Noto Serif TC（標題）/ DM Sans + Noto Sans TC（內文）/ JetBrains Mono（數字）
- **設計系統**：施昱廷個人品牌 CIS v1.3（夜霧深黑 + 橄欖樹皮 + 卡其米 + 薰衣草）
- **部署**：Cloudflare Pages（自動從 `main` 分支部署）

## 本地預覽

```bash
open index.html
```

或起一個 local server：

```bash
python3 -m http.server 8000
# 開 http://localhost:8000
```

## 結構

```
.
├── index.html              # 單檔網站主體
├── answers.json            # 內容資料層（供日後重生 / 重排版用）
└── assets/
    ├── hero.jpg            # Hero 形象照
    ├── about.jpg           # About 區形象照
    ├── articles/           # 專欄文章封面圖
    └── events/             # 活動現場照片輪播
```
